## 从 Beav 借鉴的三个设计（自建实现）

| 设计 | 作用 |
|---|---|
| `authHandoff` | 遇登录/验证码就把标签页交还人工，返回结构化等待态 → 映射到内核 approval 机制 |
| `botDetect` | 动页面之前先探测风控，命中就停止自动化 |
| 分级审批 | 读操作免审批，写操作与发布需审批 |

## 六条铁律（单账号版）

1. **绝不浏览器直连内核**（内核带 shell）
2. **绝不 AI 全自动发布**（2026 封禁 AI 托管账号已处置 80 万+）
3. **绝不爬别人的小红书数据**（只回采自有账号）
4. **绝不重复发高度相似内容**（同号也判低质，60% 是判定线）
5. **绝不省 AI 标识**（贴条不影响流量，不标识才违规）
6. **绝不复制 Beav 源码**（MIT 非商用，只可借鉴设计）
