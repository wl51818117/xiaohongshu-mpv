# 需求采集助手（浏览器扩展）

在你正在浏览的**小红书 / 抖音**网页上点一下，把看到的内容存进工作台需求库。

## 为什么做这个

需求库是整条链路的输入端，但它空着的时候选题引擎会**明确拒绝工作**
（这是刻意的：没有真实需求时生成选题，本质还是 AI 拍脑袋）。

而「需求从哪来」这件事，最快的路径是：**你刷到好内容时顺手存一下**。
所以做成扩展而不是让你专门开个工具——降低动作成本，才做得下去。

---

## 合规边界（重要，请先读）

这个扩展**是人工浏览的辅助记录工具，不是爬虫**。区别在哪：

| | 爬虫 | 本扩展 |
|---|---|---|
| 触发 | 程序自动批量 | **你手动点击** |
| 登录 | 程序处理账号密码 | 复用**你自己**的浏览器登录态 |
| 访问量 | 成百上千条 | 一次一条 |
| 反爬 | 逆向 X-Bogus 等安全参数 | **完全不涉及** |
| 个人信息 | 大量采集 | **不采集** |

**它严格守四条线**（代码里有注释，后端还有第二道拦截）：

1. **只在你点击时采集** —— 没有任何定时器、轮询、自动翻页
2. **只读 DOM 已经渲染出来的内容** —— 等价于「你眼睛看到什么就记什么」
3. **不采用户可识别信息** —— 不要评论者昵称/头像/用户 ID
4. **遇到验证码/登录墙就停** —— 不尝试绕过

> 为什么要这么写：建湖「代拓客」案认定该软件「非法获取平台用于反爬虫的
> X-Bogus 安全防护参数」→ 判定为侵入，判刑 3 年。
> 判定标准是**有没有突破技术防护**。本扩展不碰任何防护参数，
> 只是把你已经看到的内容记下来。

**后端双重保险**（不依赖扩展自觉）：
- `CollectIn.model_config = {"extra": "forbid"}` —— 多传字段直接 422
  （Pydantic 默认 `ignore` 会静默丢弃，实测踩过这个坑）
- `_assert_safe()` 显式检查 `FORBIDDEN_FIELDS`

## 安装（Edge / Chrome 通用）

1. 打开 Edge，地址栏输 `edge://extensions/`
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」，选择本目录：`browser-extension/`
4. 装好后，访问小红书网页版，右下角会出现紫色「＋采集」按钮

> 首次打开 `https://www.xiaohongshu.com/explore` 时扩展才会注入。

## 使用

1. 正常用你的账号浏览（**扩展不碰账号密码**，它只是读页面）
2. 看到有价值的内容 → 点右下角「＋采集」
3. 顶部提示「已存入素材 #N（互动 3349）」
4. 到工作台「素材库」或「需求采集」页查看

弹窗里能看到采集状态与最近记录。

## 支持的站点

小红书、抖音、微博、知乎（淘宝/京东为后端白名单预留，扩展暂未注入）

**不在名单里的站点会直接拒绝**，不会「先收下再说」。

## 采到什么

| 字段 | 说明 |
|---|---|
| 标题 / 正文 | 页面上渲染出来的内容 |
| 话题标签 | 小红书的 #话题 |
| 互动数 | 赞/藏/评（**只有数字，没有是谁**） |
| 博主昵称 | 公开显示名，仅作来源标注 |
| 来源 URL | 用于回溯核对 |

**不采**：用户 ID、头像、评论者信息、任何可识别个人的数据。

## 常见问题

**Q：按钮没出现？**
- 确认在 `*.xiaohongshu.com` 域下
- 刷新页面（扩展是在 `document_idle` 时注入的）
- 检查 `edge://extensions/` 里扩展是否已启用

**Q：提示「后端未启动」？**
工作台后端要在 8000 端口：
```bash
cd backend && ./.venv/Scripts/python.exe -m uvicorn app.main:app --port 8000
```

**Q：提示「页面要求安全验证」？**
**这是正常的** —— 扩展不会绕过验证。你手动过了验证，刷新页面即可继续。

**Q：采集的内容会被判原创吗？**
会被。浏览器采来的是**别人家的内容**，`originality_risk` 标为 `high`。
它进的是**素材库**（当灵感/线索用），不是直接发。
要发的话得走选题→重写，且**必须加 AI 声明**。

## 隐私

采集的内容只存在**你本机**（`backend/data/workbench.db`），不发往任何第三方。
扩展只与 `http://127.0.0.1:8000` 通信。
