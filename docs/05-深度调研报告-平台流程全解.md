# 小红书电商内容运营端到端流程调研（面向自动化内容生产工作台设计）

> 调研时间：2026-10-04｜信源优先级：官方公告/官方平台 > 第三方数据平台/媒体 > 行业服务商
> **标注体系**：`【官方】`=小红书官方公告或规则明文；`【行业】`=第三方运营机构/服务商经验口径（无官方背书，仅供参考）；`【推测】`=本次调研基于多源交叉推断，无直接信源

---

## 0. 结论先行：对系统设计最关键的 8 条

1. **官方 API 拿不到「竞品/全网笔记数据」**。小红书开放平台的笔记类接口只覆盖「已授权账号自有数据」+ 少量商品/搜索域，跨账号抓取在技术与法律上均被堵死。系统里「竞品选题库」这一环**必须依赖第三方数据平台（付费）**，不能自己爬。【官方+司法判例】
2. **爬虫不是「灰色地带」，是「有判例的灰色地带」**。2025 年上海知识产权法院二审某企业爬取小红书笔记数据对外售卖、调用 294 万次、获利 11 万元，判赔 **110 万元**不正当竞争。爬虫的可用性边界是「自用少量、不破技术措施、不二次售卖」。【官方判例】
3. **2026 年最重要的算法变化是「搜索流量 + 语义理解」双升级**，不是 CES 权重。优质笔记搜索曝光占比普遍突破 55%，30% 用户直接打开小红书就是搜索。选题系统必须从「追热点」转向「长尾词布局」。【行业】
4. **AI 内容已被合规化，但没被禁止**。官方明确「可以用 AI 辅助剪辑/配音/字幕/调研/二次创作」，**必须主动标注**；2026-08-07 新规把标识范围从「单篇笔记」扩展到「账号身份」（AI 创作者 / AI 虚拟人职业标签）。日均打标笔记超 30 万条。系统必须有 AI 声明字段，且不能帮用户规避标注。【官方】
5. **平台明确反对「云端 AI 工具/手机脚本自动运营账号」**。这是自动化工作台最危险的边界：自动化「生产内容」可以，自动化「运营账号」（自动评论/自动私信/自动养号/自动刷互动）明确违规。【官方】
6. **冷启动窗口是发布后 60 分钟的三层赛马（5min/30min/60min）**，但**互动必须来自真人**。系统可做「提醒 + 素材准备 + 收录自查」，不能做「自动评论/自动点赞」。
7. **投流（薯条/聚光）的判定阈值是明确的、可直接写进代码**：薯条要求封面点击率 ≥5% 且完读率 ≥40%；聚光侧建议 48h 赞藏 ≥100 且点击率 ≥3% 再投。这是系统里最可靠的「自动投流触发条件」。
8. **私域导流是明令禁止的**。2025-03-12《交易导流违规管理细则》+ 私信频次限制（陌生人 24h 内 1 条、累计 ≤3 条）。系统不应提供任何「导流话术生成」能力，这是产品红线。

## 1. 账号基建与定位

### 1.1 3P 定位模型

| 维度 | 含义 | 判断标准 |
|---|---|---|
| **Passion** | 深耕赛道 | 只做一个垂直细分，不跨赛道 |
| **Proficiency** | 核心优势 | 你能持续输出什么（写 10 篇后是否还有话说） |
| **PainPoints** | 用户痛点 | 用户看完获得什么价值 |

**定位公式**：`垂直赛道 + 目标人群 + 核心价值`【行业】

**系统设计含义**：账号档案是一个**结构化实体**，字段至少包含 `赛道ID / 目标人群画像 / 核心价值主张 / 内容配比配额 / 视觉符号规范（主色≤3、字体≤2、封面模板）`。系统应在发布前校验：当一篇笔记的赛道标签与账号 `赛道ID` 匹配度低时告警。

### 1.2 垂直度对流量池的影响

- 平台用 **超 2000 维标签**分析用户兴趣，标签越精准触达越有效；**深耕垂直的账号匹配效率远超泛化账号**。【行业，机制描述】
- 定位验证的量化方法（值得直接做成系统功能）：
  - **内容标签重合度验证法**：发布后系统自动打的推荐标签，与账号定位核心词比对，**重合度 < 60% 即判定内容偏离定位**。
  - **评论区高频疑问诊断**：批量导出评论做词云聚类，按「疑问频次 × 影响定位清晰度」排序。「你到底是卖什么的?」≥5 次 = 商业定位模糊；「你是不是专门做这个的?」≥5 次 = 人设标签不清。【行业，来源为小红书电商学习中心内容】
- **流量平权**：超 50% 的大盘流量持续向千粉以下创作者倾斜；2026 年新号与百万粉账号初始流量池标准一致（200-500 曝光）。【行业/官方盛典口径】

### 1.3 主页包装标准（可做成 checklist 校验）

| 项 | 规格 |
|---|---|
| 昵称 | 名字 + 赛道关键词（利于搜索收录） |
| 头像 | 真人高清 / 品牌统一 LOGO，拒绝模糊网图 |
| 简介 | **三段式**：我是谁（垂直领域深耕）｜做什么（持续输出 XX 干货/避坑）｜能给你什么（帮新手少走弯路）。**禁止站外导流** |
| 背景图 | 贴合赛道，强化人设 |
| 置顶 3 篇 | ① 自我介绍/新人必看 ② 高收藏干货 ③ 爆款标杆 |

**新号权重养护**【行业】：
- 前 7 天**不批量发稿、不硬广导流、不频繁改资料**
- 每日 30 分钟精准互动：刷垂直赛道笔记、点赞收藏、优质评论 → 让算法打标账号垂直属性
- 有说法称「注册后正常浏览 3-5 天再发内容」可让系统正确打标【行业】

> ⚠️ **系统设计红线**：养号/自动浏览/自动点赞属于「模拟真人行为」，与官方反对的「利用云端 AI 工具或手机脚本自动运营账号、冒充真人互动」高度重叠。**不建议自动化**。

### 1.4 对标账号调研标准动作

固定输出物（建议做成标准化报告模板）：
1. 找 **5 个头部 + 10 个腰部** 同赛道账号
2. 记录维度：爆款选题、封面风格、标题套路、正文结构、高互动评论
3. 统计高收藏笔记的共同特征 → **模仿结构，不搬运内容**
4. 产出：可复用选题模板 + 内容模板

**进阶技巧（高价值）**：不看对标账号「哪篇最火」，而看**哪篇超出了它自己的平均水平**。计算对标账号最近 30 篇笔记的平均点赞，把 **高于平均 2 倍以上**的选题标为「已验证入池选题」直接拿来用。【行业】

### 1.5 该做 / 不该做（起号 0-30 天）

| ✅ 该做 | ❌ 不该做 |
|---|---|
| 单一垂直赛道深耕 | 跨赛道乱发（标签混乱 → 流量池卡死） |
| 简介三段式写清价值 | 生活碎片、日常随拍、杂糅内容 |
| 前 7 天不批量发稿 | 硬广导流、频繁改资料 |
| 置顶 3 篇结构化内容 | 追求日更（先保证质量） |
| 开通专业号（商业化前提） | 未报备商单（限流 + 剥夺蒲公英权限） |

**账号等级与商业化权限**【行业】：0-1000 粉（积累精准粉丝，不硬广）→ 1000-10000 粉（开通视频分成、蒲公英；**广告笔记 ≤ 20%**）→ 1 万粉以上（蒲公英接单、直播带货、店铺自营）。

## 2. 选题环节（系统设计的核心）

### 2.1 选题来源渠道（8 条，按可自动化程度分级）

| # | 渠道 | 采集方式 | 可自动化程度 |
|---|---|---|---|
| 1 | **搜索下拉框** | App 搜索框输入赛道词，抓联想词 10-20 个 | 🟡 半自动（需抓搜索建议接口，有风控） |
| 2 | **搜索结果页「相关搜索/大家都在搜」** | 搜词后读结果页扩展位 | 🟡 半自动 |
| 3 | **爆文评论区高频提问** | 抓爆文评论，做词频/聚类 | 🟢 全自动（数据源问题见 §3） |
| 4 | **创作中心/灵感中心热门话题 + 笔记灵感** | 官方入口，人工点击参与 | 🔴 人工（部分可截图/OCR） |
| 5 | **聚光关键词规划工具（以词推词）** | 官方，需开户 | 🟢 自动（API/导出） |
| 6 | **千瓜/新红等第三方话题榜、热搜词库** | 付费导出 | 🟢 全自动 |
| 7 | **自己笔记评论区 + 私信 + 客服问题** | 导出 | 🟢 全自动 |
| 8 | **AI 灵感生成（LLM 扩词）** | 核心词喂给 LLM 做九宫格/因子叠加 | 🟢 全自动 |
| 9 | 跨平台搬运（知乎/抖音/B站同赛道爆款） | 人工调研 | 🟡 半自动 |
| 10 | 官方活动日历（618/双11/节点） | 每月初看官方活动日历 | 🔴 人工 |

### 2.2 爆款选题的量化筛选标准

**A. 竞争维度（可自动计算，最重要）**
- 同题笔记 **> 50 篇 → 慎选**；**≤ 10 篇 → 优先**【行业】
- 关键词分层（第三方工具口径，**注意口径差异**）：
  - 核心词：月搜索量 1 万+（难抢但流量大）
  - 长尾词：月搜索量 1000-10000（**性价比最高**）
  - 蓝海词：搜索量不低但只有少数笔记覆盖
- **实操验证（比工具分更可靠）**：真实搜一遍该词，看**前 20 篇笔记的发布日期和互动量**。若前 20 篇中有大量「几千甚至上万互动量的老笔记」→ 竞争壁垒已高，新号不宜正面进场。【行业，方法论非常可靠】
- ⚠️ **不同第三方工具对同一词的搜索量可能差 3 倍**。不要依赖绝对值，**看时间趋势 + 同工具纵向对比**。【行业】

**B. 选题因子叠加公式**：`人群 × 场景 × 痛点 × 形式`
例：`上班族 × 办公室 × 不长胖 × 食谱`；`大学生 × 睡前 × 瘦小腿 × 图文`
→ 九宫格法（3×3：中间核心词 + 周围人群/场景/痛点）可**一次性产出几十个候选**。【行业】

**C. 价值类型覆盖（至少占 1 种，多种叠加爆款率更高）**
情绪价值（「被理解了」）／实用价值（「这能帮我」）／信息价值（「学到了」）／经济价值（「能省钱」）

**D. 需求/竞争/变现三维打分**【行业，建议直接做进选题库】
- 需求维度：有无搜索/评论证据
- 竞争维度：竞争激烈程度
- 变现维度：能否引导商品/服务
- **纯流量选题 : 变现选题 = 7 : 3**

**E. 痛点句式识别（评论区挖词的信号词）**【行业】
`求推荐` `怎么买` `在哪里` `多少钱` `适合XX吗` `XX能吗` `和XX比哪个好`
→ 这些句式本身就是未被满足的搜索需求，直接转为选题。

**F. 赛马测试机制（必须有的验证环节）**
选题不能凭信心，需要 3 阶段验证，对应 **阅读高 / 互动高 / 回搜高** 三类不同素材：
- 「互动型」素材 ≠「回搜型」素材，需多轮测试分别验证
- 测试的评论区互动本身会反哺痛点确认

**明确不做的选题**【行业】：自嗨流水账、无信息增量、纯广告硬广。

### 2.3 选题库设计（建议 schema）

**分库结构**（行业标准做法）：
1. **爆文库**：我品 + 竞品的爆款（含拆解字段）
2. **标题库**：所有高点击标题，不论是否本行业
3. **图片/视频库**：高清**无版权**素材（严禁使用禁止商用素材）
4. **工具库**
5. **名词库**：垂直行业专有名词

**单条选题字段设计**（建议直接落库）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `topic_id` | string | 主键 |
| `title_draft` | string | 候选标题（≤20 字） |
| `keyword_target` | string | **目标长尾词**（核心字段，用于跟踪排名） |
| `keyword_source` | enum | 下拉框/评论挖词/聚光/千瓜/AI生成/跨平台 |
| `search_volume_est` | int | 搜索量估算（标注来源工具） |
| `note_count_20` | int | 该词下前 20 篇笔记数（竞争度代理指标） |
| `competition_level` | enum | 蓝海(<10) / 适中(10-50) / 红海(>50) |
| `value_type` | enum | 情绪/实用/信息/经济（可多选） |
| `persona` / `scene` / `painpoint` | string | 因子叠加三要素 |
| `content_ratio_tag` | enum | 干货 / 热点 / 人设（用于配比校验） |
| `monetization_link` | string | 关联商品/服务（可空） |
| `heat_source_note` | string | 来源爆文 note_id |
| `status` | enum | 候选/待写/已写/已发/已验证/淘汰 |
| `publish_note_id` | string | 发布后回填，用于效果归因 |
| `verified_flag` | bool | 是否经赛马测试验证 |

**分类体系**：按「赛道 → 一级类目（干货/热点/人设）→ 关键词簇」三层。

**储备节奏**【行业】：
- 每周储备 **15-20 个**选题入库（不要临时想题）
- 另一版本口径：每周新增 5 个、淘汰已发布/过时，保持 **20 个待发布库存**
- 选题测试阶段只留 **10-20 个**高热度高讨论度选题做第一波
- 节点选题**提前 14 天备稿**（9月开学军训 / 10月国庆出行 / 11月双11收纳 / 12月跨年返乡）

### 2.4 内容配比

| 配比（7:2:1） | 类型 | 作用 |
|---|---|---|
| **70%** | 干货 / 测评 / 教程 | 拉高收藏、搜索流量 |
| **20%** | 热点 / 季节 / 场景 | 拿推荐流爆发 |
| **10%** | 人设 / 个人经验故事 | 提升粉丝粘性、关注转化率 |

另一版本口径（按栏目）：**引流款 60% + 专业款 30% + 人设款 10%**。两者可兼容——系统按 7:2:1 做月度配额校验即可。
**商业笔记占比 ≤ 20%**（1000-10000 粉阶段）。

## 3. 数据抓取与选品侧（最关键的现实约束）

### 3.1 官方开放途径（能力与门槛对照表）

| 渠道 | 能拿到什么 | 门槛 | 可否商用 |
|---|---|---|---|
| **开放平台 open.xiaohongshu.com** | **仅自有授权账号**的笔记详情/用户作品列表/商品搜索；v4 版本新增**视频播放量、完播率**；付费高级权限可开**评论情感分析** | 企业开发者资质（营业执照）；个人需身份证正反面 + 手持照；每类权限单独勾选**人工复核**；审核 1-3 工作日（部分口径 2-4 周） | ✅ 可（受协议约束） |
| **聚光 ad-market.xiaohongshu.com** | KOS 账号**报表数据**（笔记曝光/互动）；**关键词规划工具**（搜索量、竞争热度、建议出价）；搜索词报告 | 聚光超管账号注册开发者（资质可复用）；需**全新干净手机号**（未注册过聚光/千帆/星火/MCN/代理商） | ✅ 可 |
| **蒲公英 pgy** | 博主粉丝画像、报价、**近 30 天 GMV**、种草指数、笔记种草/直播转化数据、历史商业笔记 | 品牌方需企业专业号蓝V认证 + 营业执照；个人号不能作为投放方 | ✅ 可 |
| **千帆** | 商家商品/店铺/直播管理、商品笔记、直播计划、活动报名 | 电商入驻 | ✅ 可 |
| **创作者中心** | 自有笔记曝光/点击/完读/互动/涨粉、**笔记诊断**（是否限流/标签不匹配） | 零门槛 | ✅ 只能看自己的 |

**关键限制**：
- **OAuth 2.0**；access_token 有效期 **2 小时**（需自动刷新）；敏感操作需 **HMAC-SHA256 签名**；timestamp 误差 ≤300 秒
- 频率限制：普通接口 **200 次/分钟**，企业专业版可申请提至 **500 次/分钟**（另一口径称免费版 100 次/分钟）
- 单次 URL 长度 ≤ 2048 字符
- URL 白名单需报备：`dm.shukuajing.com`（帆软文档中的官方开放平台网关示例）
- **「笔记搜索」类接口即便存在于第三方文档中，也不等于官方授权开放给普通开发者**——多数需要品牌/伙伴级资质

> **系统设计结论**：官方 API 只能支撑「**自有账号数据分析 + 投流 + 关键词规划**」三件事。竞品/对标/爆文库必须走第三方。

### 3.2 第三方数据平台

**正文排版（手机端「332 法则」）**：
- 每段 ≤3 行，段间空一行；重点句单独成段并加粗/换色
- **前 80 字埋价值 + 主关键词**（否则被折叠）
- 首行不要空格缩进（会被判机器号）
- 字号正文 14-16pt，行距 ≥1.5
- emoji ≤5 种，每 2-3 段用 1 个；小标题符号固定一套（🔹▪️✅❌）；板块分隔用 `———` 或 `┈┈┈┈`；列表用 ▪️/✅ 起头

**正文三段式结构**：
1. 开头 50 字：直击痛点/反常识，留住阅读
2. 中间主体：分点输出干货、真实体验、可落地 → 提升读完率与收藏
3. 结尾：总结 + 轻互动，抛出问题引导评论

**埋词四维布局**：标题、正文首段、小标题、标签 自然植入人群词/场景词/长尾需求词。**2026 语义理解（BERT/GR-Inference）看整体语义相关性，核心词自然出现 2-3 次即可，硬堆同词 5 次会触发限流**。

**标题公式（4 套）**：
1. 人群标签 + 痛点 + 解决方案：「油敏肌夏天｜别乱涂水乳，3 个避坑要点」
2. 数字 + 结果：「7 个租房收纳技巧，小户型直接变大」
3. 反常识 + 警示：「不要再乱买防晒，90% 人踩坑」
4. 提问代入：「有没有人和我一样，护肤越护越烂？」

补充公式（9 种填空）：数字+结果 / 人群+场景+方案 / 痛点+解法 / A vs B / 步骤型 / 时间限定 / 反常识 / 身份+干货 / 悬念留白

**高点击封面 6 型**：对比型（前后对比）/ 数字型 / 人物出镜型（点击率普遍高于纯图文）/ 清单型 / 痛点型 / 干货合集型

- 滤镜化旧素材掉量明显，**新素材生命周期约 15 天**

### 4.3 AI 生成文案：去 AI 味

**官方明确边界**【官方，2026-08-07《AI治理规则公告》】：
- ✅ **允许**：AI 辅助剪辑、配音、字幕等后期处理；AI 做内容调研、素材参考、二次创作
- ✅ **鼓励**：主动标注 AI 生成内容/AI 虚拟人身份，「**不会影响流量**」，率先亮明身份者有机会优先体验平台 AI 新工具
- ❌ **反对三类**：
  1. **信息不透明**：AI 生成真人形象/图片/视频却不声明；大量 AI 改写、原创度存疑
  2. **AI 工具违规运营账号**：利用云端 AI 工具或手机脚本自动运营、冒充真人互动；传授 AI 洗稿/去水印/规避审核的做号方法
  3. **欺骗或低质内容**：AI 合成他人声音面孔；捏造新闻事件/社会热点引流；批量生成低俗擦边猎奇内容

**标注要求（系统必须实现）**：
- 内容端：发布时【设置】→【内容类型声明】→ 勾选【笔记含 AI 合成内容】
- 账号端：编辑主页 →【职业】依次选择「**AI创作者**」「**AI虚拟人**」→ 公开展示身份标签
- 显式标识：笔记时间与 IP 旁显示「笔记含 AI 生成内容」；隐式标识：文件元数据，**不得删除或篡改**
- 未主动声明但被识别 → 平台统一补加明显标识（日均打标 > 30 万条）

**平台 AI 识别（据行业口径，准确率 ~95%，非官方确认数字）**：
- 语义层：套话、模板化表达、逻辑空洞
- 行为层：创作时长、修改频次、配图来源
- 互动层：AI 内容互动转化率远低于真人创作

**「AI 提效 + 人工赋魂」原则**【行业】：AI 负责框架、基础文案、视觉素材；人工负责个人观点、真实体验、差异化细节。**建议人工修改比例 ≥30%**。
**同质化阈值**：同一关键词生成的多篇内容相似度 **> 70% 会被判定为低质内容，直接进入流量池底层**（行业口径）。

**「去 AI 味」实操（去 AI 味 = 加具体的人味细节）**：
- 写第一人称日记体（有情绪起伏、有具体时间/数字/场景）
- 加「不完美」细节：踩坑、翻车、犹豫
- 加真实体感描述（价格区间、使用时长、具体场景）
- 口语化重写，短句化，删掉总结性套话
- 结尾留悬念或提问

| 比例 | **3:4 竖版**（1080×1440） |
| 真实感 | 优先「写实摄影风」，避免明显 AI 塑料感；美妆/护肤/穿搭类**过度美化会导致「虚假种草」违规** |
| 模特 | 亚洲模特、多样肤质/体型；避免欧美面孔（与目标受众不符）；未成年人出镜需肖像授权 |
| 场景图 | 生活化场景（居家/办公/旅行）优于棚拍纯白底 |
| 拼图对比图 | 前后对比是 6 大高点击封面之一，**但禁止伪造使用效果**（滤镜 P 图伪造前后变化属违规） |
| 禁项 | 水印、二维码、联系方式；未授权品牌 LOGO/字体/图片 |

**提示词结构（5 层次）**：
```
主体描述（谁/什么/在哪）
→ 动作与情绪（做什么/表情/幅度）
→ 环境与光影（时间/天气/光线方向/冷暖色调）
→ 镜头语言（景别：远/中/特写；运镜：推拉摇移；焦距：广角/标准/长焦）
→ 风格与画质（写实/胶片/电影感；4K/8K）
```

**通用反向提示词（直接可用）**：
`五官扭曲、大小眼、歪嘴、畸形手部、六根手指、残缺肢体、模糊、低清、水印、文字logo、杂乱杂物、暗沉发黑、色彩溢出、锯齿、人体变形、多余肢体`

**拼图排版参数**（AI 出图后仍需人工/程序排版）：
- 文字面积 ≤30~40%，主标题 3-7 字放中上 1/3
- 九宫格顺序：封面 → 痛点场景 → 3-7 核心内容 → 总结卡 → 互动彩蛋

### 4.5 AI 生视频

**常用工具对比**：
| 工具 | 特点 | 小红书适配建议 |
|---|---|---|
| **即梦（Seedance 2.0 / 2.5）** | 抖音生态，Seedance 2.5 原生支持 **30 秒直出**，超长模式最长 **3 分钟**；首尾帧/智能参考锁角色一致性 | 优先（生态顺、免费积分） |
| **可灵 Kling** | 图生视频稳、真实感强 | 优先图生视频模式 |
| **Runway** | 海外通用 | 中文生态适配一般 |
| **Vidu** | 生数科技 | 参考图生视频 |
| **海螺 Conch** | 快手系 | 可用 |
| **SkyReels / 智谱清影** | 开源/国产 | 需自部署 |

**适配小红书的硬性要求**：
- **9:16 竖屏**（横屏视频可被当"深度观看"信号加权，但分发上竖屏为主）
- **AI 单镜头最佳时长 3-5 秒**（画面稳定不崩坏）→ 必须先做分镜拆解，再逐镜生成
- 分镜标注字段：镜头画面内容 / 视角 / 运动方式 / 光影风格 / 时长 / 匹配台词
- **角色一致性方案**：上传定妆照（正面半身高清）→ 智能参考勾选「人物长相/角色特征」→ 调脸部参考强度和主体参考强度 → **提示词里只改场景/动作/服装/镜头，不描述五官细节**
- 首尾帧必须保持**相同角色、场景、服装、道具、光照**的一致性
- 必加**黄金约束词**（防崩）：面部清晰不变形、人体结构正常、动作流畅不僵硬、画面稳定不闪烁、无重影无畸变、4K高清、电影感
- 产品展示图：居中构图、背景干净、避免小字和复杂标识
- 导出前必查：水印、版权、多余人物、文字变形

## 5. 发布与冷启动

### 5.1 发布字段清单

**图文**
- 标题（≤20 字，前 8-13 字含核心长尾词）
- 正文（300-800 字，三段式，前 80 字埋词）
- 图片 4-8 张（3:4，1080×1440）
- 话题标签 3-5 个
- **内容类型声明（AI 标注）** ← 系统必做
- **地理位置（POI）**：本地号必带，否则不进 LBS 流量池
- 可见性

**视频**
- 封面（视频封面 = 关键帧，3:4）
- 标题、正文、标签（同上）
- 视频文件（9:16，≤500MB，≥1080P）
- **AI 声明 + POI**

**带货/商品关联**
- 关联商品卡片 / 购物车（需已开通店铺）
- 选品中心 → 商品笔记；千帆侧配置
- 蒲公英商单笔记自动带「**品牌合作**」商业标识（完成官方报备）
- 位置（POI）：本地探店类必带
- 直播预告/关联直播

### 5.2 冷启动关键动作（前 60 分钟三层赛马）

**赛马节奏【行业】：发布后 5min / 30min / 60min 三层横向赛马，系统每 5 分钟对比同时段内容。前 1 小时数据基本定整篇笔记命运。**

**必做清单**：
| 时机 | 动作 |
|---|---|
| **发布前** | 敏感词检测、错别字检查、图片描述补充关键词、确认未限流（笔记诊断无「内容质量待优化」「标签不匹配」提示） |
| **发布后 10 分钟** | **用小号搜索笔记全称，确认正常收录**（搜不到 = 违规或被判低质，需修改或申诉） |
| **发布后 10-30 分钟** | **自己置顶一条 ≥15 字的长评论**，抛出讨论话题（长评论权重远高于「666」水评） |
| **发布后 5-60 分钟** | 前 5 条真实用户评论，**5 分钟内快速回复**，拉高评论质量与转粉率 |
| **发布后 1 小时内** | 引导真实互动，**禁止刷水评/刷赞** |
| **发布后 2 小时** | 再次搜索确认收录（小红书收录 + 初始池 200-500 曝光窗口） |

**黄金发布时间**：
- 通用：**12:00-13:00、19:00-22:00**
- 三段式（某行业实测口径）：早 7:30-8:30（曝光 +27%）、午 12:00-13:30（互动 +34%）、晚 19:00-21:30（**评论 +41%，最佳**）
- 另一口径：早 7:00-9:00 / 午 12:00-14:00 / 晚 18:00-22:00；**知识类 22:00-23:30**（用户决策时段）
- 赛道差异：美妆 19:00-21:00；知识 22:00-23:30；家居 12:00-14:00
- **提前 10 分钟发布**以留审核时间

**更新频率**：
- 新号：每周 3-4 篇起，优先质量，**不盲目日更**（另一口径：日更或隔日更建立基础内容库；1000 粉后降到每周 3-5 更）
- 「稳定」比「高频但断断续续」更有价值
- 硬性节奏参考：有Skill建议**每天最多 2 篇，间隔 ≥2 小时**

### 5.3 CES 评分 / 流量池（2026 口径）

**分发链路**：审核收录（AI 审核 <5 秒，高风险转人工）→ 标签匹配（超 2000 维标签）→ 阶梯流量池 → CES 评分筛选 → 搜推互通放大

**流量池与晋级门槛**：
| 层级 | 曝光量级 | 关键门槛 |
|---|---|---|
| 冷启动池 | 0-200（发布后 2 小时，推给粉丝 + 兴趣匹配人群） | CTR 不达标即停止 |
| 初始池 | 200-500 | **图文 CTR ≥2.5% / 视频 CTR ≥4%**（另口径：CTR ≥8% + 互动率 ≥5% + 完播率 ≥45%） |
| 中级池 | 5,000-20,000 | CES 达标、**收藏率 ≥3%**、评论质量高 |
| 高级池 | 100,000-5,000,000 | **转化率 >2%、日均增量 >300%** |
| 现象级池 | 5,000,000+ | 成为爆文模板 |

**CES 公式（2026）**：
```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```
**权重解读**：关注(8) > 评论/转发(4) > 点赞/收藏(1)。**点赞权重持续降低，收藏/评论/转发是冲爆款池核心。**

**CES 质量化调整**【行业】：
- **长评论（≥8 字）权重是普通评论的 3 倍**
- 图文停留 ≥25 秒、视频停留 ≥1分10秒 的深度阅读为高权重信号
- **截屏分享**行为纳入「深度互动」指标
- 单纯点赞对 CES 的加分效应**已不足 10%**

**淘汰机制**：若连续 3 天互动率下降 > 30%，系统可能停止推荐。

**星云 5.0 推荐得分（管排位，与 CES 管门槛是接力关系）**：
```
推荐得分 = (基础质量分 × 0.3) + (用户互动分 × 0.4) + (商业价值分 × 0.2) + (社交关系分 × 0.1) − 违规扣分
```
五大引擎：用户画像引擎（潜在兴趣推理）/ 内容理解引擎（**dots.vlm1 多模态视觉语言模型，语义理解准确率 92%**）/ 匹配排序引擎 / 流量调控引擎（**遗忘算法**：连续浏览 3 篇同类后插入 1-2 条不同场景笔记）/ 商业平衡引擎

**流量入口占比**：推荐页 ~60%、搜索页 30%~65%（占比持续攀升）、关注页 ~10%、本地页 ~10%
**搜索数据（2026）**：月活 > 4 亿，日搜索量 **8 亿次**，搜索流量占比逼近 **50%**；约 30% 用户打开 App 直接搜索

**账号权重影响因素**：深耕垂直领域、保持 100 分信用分、稳定更新频率、历史内容质量、违规与限流风险
**2026 新增**：**账号信任分机制**——长期输出真实内容的素人账号获得更高信任分，流量优先级甚至反超虚假粉堆砌的博主。

**视频初始曝光倾斜**：视频内容初始曝光量比图文**高约 30%**（另一口径：搜索流量优质笔记占比突破 55%）

**图文 vs 视频决策**：
- 图文：成本低，适合干货/教程/测评；主打搜索承接；**生命周期 15-20 天**（有素材 15 天说）
- 竖屏短视频（1-3 分钟最优）：平台扶持中长视频，**长尾流量可达 90 天**，易建信任，适合人设 IP/场景/探店
- **最优方案：图文 + 视频双轨**。图文抢搜索，视频冲推荐；**图文爆款可二次改编成视频二次分发**

> ⚠️ **重要提醒**：以上 CES 公式与流量池门槛**均为第三方/行业口径，官方从未公开确认**。官方唯一公开的是「五步分发流水线」的存在与「超 50% 大盘流量向千粉以下倾斜」「流量平权」等原则性表述。系统在设计自动化决策时，应把这些数字标注为**经验参数**并允许配置，而非硬编码为「平台规则」。

### 5.4 投流工具

**薯条（个人/小博主）**

前置门槛（**可直接作为系统自动投流的触发条件**）：
1. 创作中心→数据概览，筛近 7 天内**封面点击率 ≥5% 且完读率 ≥40%** 的笔记
   （另一口径：48h 赞藏 ≥100 且点击率 ≥3%；CTR > 8% 视为优质素材；互动率 > 5% 具备追投价值）
2. 剔除评论区大量质疑/无关提问/负面情绪的笔记
3. 笔记诊断无「内容质量待优化」「标签不匹配」「限流中」提示

投放节奏（三阶段）：
| 阶段 | 设置 | 触发条件 |
|---|---|---|
| ① 观测 | **6 小时周期 + 75 元预算**（≈5000 次曝光）作为标准化测试单元 | 首次投放 |
| ② 放大 | 启用「智能推荐」+ 叠加兴趣标签，**12 小时周期** | 首波**互动率 ≥8%** |
| ③ 收割 | CTR ≥3% 且单次互动成本 < 行业均值 → 拆 **2-3 个独立订单**，间隔 ≥2 小时 | 达标 |

三层人群定向（破圈—聚拢—收割）：
- 外层破圈：兴趣标签，勾 **3-5 个**宽泛相关标签
- 中层聚拢：搜索行为定向，输入 **2-3 个**具体关键词
- 核心收割：自定义人群 = 近 7 天互动过你笔记的用户 + 已关注你账号的粉丝

推广目标必须与笔记属性强绑定（选错导致流量错配、CTR 断崖）：
- 含购物车/商品卡片且已开店 → **商品购买**
- 纯种草无跳转链路 → **互动量**（而非「关注用户」）
- 本地生活强地域属性 → **引流到店** + 开启 LBS（否则不激活地理围栏定向）

其他要点：单日 ≤3 单且间隔 ≥2 小时；**发布后 30 分钟至 2 小时内启动**最佳；优化封面（高对比 + 8 字内文案）与标题（前 12 字含强动词）；正文前三行设明确互动指令。

**聚光（企业/商家长期投放）**

三种主力产品：
| 产品 | 位置 | 作用 | 特点 |
|---|---|---|---|
| 信息流 | 发现页 6/16/26 等「赞助」位 | 种草、破圈、测素材、养人群模型 | 流量大、意向弱、适合冷启动 |
| 搜索广告 | 搜索结果 3/13/23 位 | 截需求、收精准客、降获客成本 | 用户主动搜，意向强、转化高 |
| 全站智投 | 系统自动分配 | 放大已有爆款 | 适合模型稳定后放量，**不适合新号** |

投前 3 条件（没有就别开户）：
1. **先有「能自然跑」的笔记**：先发 5-8 篇，看 48h 数据
2. **素材要赛马**：冷启动至少备 **3 套封面 + 3 个标题角度 + 图文/短视频各来点**（「531 法则」：首轮不少于 5 套差异化封面文案，取 TOP 30% 定向加投）
3. **承接链路先打通**：私信自动回复、留资表单 ≤3 字段、商品卡/店铺页/企微路径、客服 1 分钟内回

计划搭建结构：**一个计划 = 一个目标；一个单元 = 一篇笔记/一个商品**（别把 10 篇塞一个单元，也别同篇建 5 条计划互抢量）
冷启动参数：日预算 **300-500 元/计划**；出价自动出价或 oCPC，初始 = 系统建议价 **0.8-1.0 倍**；定向年龄+性别+地域，兴趣**不叠超过 3 层**；时段前期全天跑 **3-5 天**再缩到 19:00-23:00；**学习期 24-48h 内别老改，每天调 ≤2 次，幅度 ≤10%**

盯盘指标：CTR、CPC、CPE（千次曝光成本）；某定向维度成本持续高于行业均值 **20%** → 暂停或调整标签组合

新手标准打法：**薯条测素材 → 信息流种草 → 搜索收割 → 稳定后全站智投放量**

## 6. 数据复盘

### 6.1 必看指标与合格线

| 指标 | 合格线 | 低于则 |
|---|---|---|
| **点击率（封面 CTR）** | 图文 ≥2.5%（另一口径 ≥3%，优质 >5%/8%） | 优化封面 + 标题 |
| **完读率 / 完播率** | >40%（视频加权项 >45%，爆款 >65%） | 开头钩子弱、内容冗长 |
| **收藏率** | >5%（另一口径赛道基准 >3%，中级池门槛 ≥3%） | 内容干货不足、无复用价值 |
| **互动率** | ≥5%（爆款 >8%） | 缺少痛点、缺少互动引导 |
| **平均停留时长** | 图文 >30 秒 / 视频 >60 秒 | 内容无吸引力 |
| **转粉率** | — | 浏览高转粉低 → 账号定位/简介没体现价值 |
| **搜索流量占比** | — | 判断 SEO 优化效果 |
| 赞藏比 | >1:10 为优质 | — |
| **搜后率** | — | 极高种草转化力信号，触发第二轮流量助推 |
| **3 秒完播率 / 均播时长** | — | 完播 <30% 需优化开头 |
| 信用分 | 满分 100 | 低于 100 影响账号权重 |

**决策逻辑（按此顺序排查，不要先看浏览量）**：
```
点击率 → 完读/完播率 → 收藏率 → 评论质量 → 转粉率
```
- 点击率低 → 优先改封面标题
- 点击率高但收藏低 → 内容缺少实操干货
- 浏览高但转粉低 → 账号定位、简介没体现价值
- **评论区高频提问 → 直接作为下一批选题**（复盘→选题的闭环）

### 6.2 复盘节奏

**单篇笔记复盘**：发布后 1 / 3 / 7 / 14 天各记录一次（与排名监测同步）

**周复盘**：
1. 筛选本周数据最好的 **2-3 篇**笔记，拆解爆款共性（选题、封面、结构、关键词）
2. 数据差笔记归类：是选题问题？封面？还是内容价值不足？
3. **提取评论区高频提问 → 作为下一批选题**
4. 更新下周选题库，复用爆款模型，淘汰低效果方向

**月复盘**：
- 内容配比校验（7:2:1 是否达标；商业笔记 ≤20%）
- 关键词库热度趋势更新（与去年同期比看季节性；与竞品比看位置；与行业均值比看是否高于大盘）
- 素材生命周期检查（**视觉素材是否已过 15 天红利期**）
- 账号标签重合度校验（<60% 则调整选题方向）

**数据工具使用节奏**：每周 1-2 次，用途是找选题不是刷数据

### 6.3 爆文复用与内容矩阵

**爆文放大 SOP**：
1. 提取爆款核心选题逻辑
2. 围绕同一方向产出 **3-5 篇同系列笔记**，复用结构、换案例换角度

**注意事项**：
- **不要一看到几百小眼睛就删笔记**——数据差优先复盘，大量删除影响账号权重；流量差笔记设「仅自己可见」
- 商业化动作：聚光批量加热、一键同步到广告投放系统

**内容矩阵**：
- 主账号：日更/周更稳定节奏

### 7.2 违禁词与虚假宣传

**8 大类明确禁止内容**（平台 AI 初审 + 人工复核双重巡检，**新发 + 历史旧笔记均不定期回溯巡检**）：

**① 站外导流（处罚最重，平台最高优先级红线）**
- 笔记/评论直接留微信、vx、手机号、QQ、二维码、淘宝口令
- 话术暗示：「看我头像拿资料」「私我要联系方式」「平台不能说，去XX找我」
- 矩阵大小号配合：大号评论引导关注小号，小号主页挂站外联系方式
- 图片角落加水印、截图露出快递单微信、视频背景一闪而过联系方式
- 谐音、缩写、拆分文字、图片水印暗藏联系方式均会被识别
- **处罚**：笔记下架、警告扣分，多次违规限制私信/商业权限，严重账号封禁
- **合规替代**：全部沟通站内闭环，引导私信、看主页合集、使用企业号官方电话组件

**② 虚假宣传 & 夸大功效**（美妆/护肤/食品/医美重灾区）
- 极限词：最、第一、顶级、100%有效、根治、全网最好、永不复发；**谐音变体「zui」「№1」也会命中**
- 美妆护肤：普通护肤品宣称美白/祛斑/祛痘根治，无特证写特殊功效
- 食品保健品：普通零食宣传治病、调理疾病、降血压
- 效果造假：重度 P 图对比、滤镜伪造前后变化、编造没发生的使用体验
- 理财：承诺保本保息、稳赚不赔、晒虚假收益截图诱导跟单
- **合规替代**：写个人主观真实感受，功效只写产品说明书标注范围

**③ 其他 6 类**：诱导互动/违规营销/医疗违规/数据造假（永久封禁）/内容与标签不符/政治宗教成人

**平台处置数据（官方公布，治理力度实证）**：
- 某月专项处置违规账号 **179.9 万个**：虚假仿冒号 1.1 万、抄袭/同质化 42.7 万、互动数据作弊 17.8 万、违规营销 46.9 万、**水下商家 71.4 万**；查处关联风险设备下违规账号 49.5 万
- 互动作弊治理（8/22-9/20 期间）：处置账号 **7.6 万个**、笔记 **35.7 万篇**，清理虚假关注 **1.7 亿次**、虚假点赞收藏 **9.8 亿次**
- MCN 处罚：警告 / 扣保证金 / 降低结算频次 / 限制商业合作权限

**私域导流专项规则**：
- **2025-01-07 起**：专业号私信自动回复及欢迎语**禁止出现微信及电话**，强制使用官方「社媒名片」或「私信获客工具」
- **2025-03-12《交易导流违规管理细则》生效**：明确禁止通过小红书商城/直播间购物车/官方留资组件**之外**的任何形式引导站外交易
- 禁止话术：「私信获取更多优惠」「加好友享专属折扣」「私聊获取更多资料」「私信我」「评论区扣1」
- **私信频次**：陌生用户未关注/未回复前，24 小时内最多发 **1 条**，累计 **≤3 条**；普通号每天主动戳 **5-10 人**（另一口径 5 位）；**企业蓝 V 每日上限 20 人**
- 同话术发给 ≥3 人 → 触发**批量营销预警**；「薇/绿泡泡/看主页」语义追踪 → 直接禁言或封号
- **「评论区扣2 领资料」判定的法律争议**：2025-2026 年多名用户（律师、商户）因「违规留资」或「制造惊喜/悬念诱导互动」等模糊规则被封禁/限流并提起诉讼。平台规则不透明、判定依据不具体、申诉渠道低效；法律观点认为平台此类判定的程序正当性存在瑕疵。**→ 系统应避免生成任何可能被判定为「诱导互动」的话术。**

### 7.3 一机多号 / 刷量

- **官方明确：刷赞、互刷、同 WiFi 多号互刷会触发风控降权**；虚假互动不会助推流量，反而直接降低账号权重
- **双实名全量**：一身份证一号，**换号重开无用**
- 关联方风险设备：同一设备/WiFi 下多账号互动触发风控；关联风险设备下违规账号被批量查处
- 外购刷量服务：除封号外，还有**账号被盗、财产受损**风险；平台提供官方「薯条」作为合规替代
- AI 自动化红线：**利用云端 AI 工具或手机脚本自动运营账号、冒充真人互动**是官方明确反对的行为
- 限流高发行为（另一口径）：短时间发布大量笔记（疑似机器操作）、频繁编辑或删除笔记、私信留外链、笔记频繁出现其他平台名称
- 限流恢复：多数 **1-4 周**自动恢复，期间保持正常更新，**不要频繁编辑/删除**。申诉入口：笔记详情页右上角「…」→「薯币举报/帮助与客服」→「笔记/内容申诉」

### 7.4 商单合规

- 所有付费商业种草笔记**必须通过蒲公英平台报备**
- **私下接未报备广告 → 限流 + 剥夺蒲公英权限**
- 商业笔记占比 ≤ 20%
- 不得脱离平台私下定稿，全部内容走平台留痕
- 带货笔记需真实使用体验 + 商品链接，佣金 10%-30%
- 水下商家（未公示商家资质、私信或评论区暗中引导交易）：官方集中治理，71.4 万/月的量级

## 8. 自动化可行性分级（系统设计的直接依据）

### 🟢 可全自动（数据在授权范围内，无违规风险）

- 自有账号数据采集（创作者中心 / 开放平台 API）：曝光、点击率、完读率、互动、涨粉、笔记诊断结论
- 关键词库管理与趋势监控（聚光关键词规划工具 / 第三方 API）
- 选题库 CRUD、因子叠加生成（九宫格/AI 扩词）
- AI 辅助生成：标题候选、正文草稿、脚本、封面图、生图/生视频
- 违禁词/敏感词检测（零克查词、千瓜违禁词检测）
- 内容规格校验（字数、比例、标签数、埋词位置、排版规则）——**规则化校验，确定性高**
- 排名监测（无痕浏览器定时查询，记录时间线）
- 竞品/爆文数据（**通过已付费的第三方 API 或数据平台**，非自建爬虫）
- 复盘报表生成
- 投流预算/定向配置的**参数计算与建议**

### 🟡 半自动（需人工确认，或风控可控）

- 发布（图文/视频/带货/POI/AI 声明）——可通过 Playwright/MCP 自动化，但**发布字段必须人工复核**，且 100% 需人工确认
- 收录自查（搜笔记全称）
- 私域/私信互动（频次严格受限，AI 辅助回复草稿）
- 关键词排名监测（无痕窗口，可能触发验证码）
- 素材生成（AI 出图/生视频后需人工选片、修图、排版）
- 评论区运营（人工回复更快更好，AI 可辅助草拟）

### 🔴 必须人工（不可自动化 / 明确违规）

- **养号/自动浏览/自动点赞/自动收藏/自动关注**
- **自动评论、自动私信互动、自动回复（官方反对「冒充真人互动」「手机脚本自动运营」）**
- **任何刷量/互刷/多号联动**
- 账号资质认证、聚光开户、蒲公英签约
- 商单洽谈、脚本终审、品牌沟通
- 商业笔记的最终发布（合规风险高）
- 违规申诉的实质性沟通

### ⚫ 灰色地带（法律/平台风险明确，不建议做）

| 做法 | 风险 |
|---|---|
| 自建爬虫抓取小红书笔记/评论/用户数据 | **判例：110 万赔偿**；绕过技术措施即不正当竞争认定要件 |
| 抓取数据对外售卖/提供给第三方 | 判罚显著加重；已是明面违法行为 |
| 破解 x-s/x-t 签名、绕验证码、绕 IP 限频 | 「绕技术措施」是法院明确认定的要件 |
| 抓取用户手机号/住址/后台非公开数据 | 侵犯个人隐私，涉刑 |
| AI 换脸/换声发布内容 | 侵犯肖像权/声音权，平台明确反对 |
| 批量 AI 生成低俗/擦边/猎奇内容换流量 | 明确反对，且是 AI 识别重点打击对象 |
| 帮用户规避 AI 标识 | 元数据隐式标识禁止删除篡改 |
| 提供「导流话术/私信钩子」生成 | 平台判定模糊但被明确禁止；已有诉讼争议 |

## 9. 给系统的 10 条落地建议

1. **数据层做双轨**：官方 API（自有账号 + 关键词 + 投流）+ 第三方付费 API（竞品/话题/达人）。**不要自建爬虫**——判例已明确。
2. **选题库是核心资产**，字段按 §2.3 schema 设计，把「关键词 + 竞争度 + 价值类型 + 因子」结构化，支持 `因子叠加` 自动生成。
3. **关键词情报是流量主线**：聚光关键词规划（官方口径）+ 第三方趋势（相对值）双源，固定一家做纵向对比。核心词/长尾词/蓝海词三层分类。
4. **AI 声明做成硬约束**：任何 AI 参与的内容，发布表单强制勾选；账号档案加「职业身份」字段。不提供规避功能。
5. **把 §5.4 的投流阈值写进代码**作为自动建议触发器：薯条（点击率≥5% 且完读率≥40%）、聚光（48h 赞藏≥100 且 CTR≥3%）。
6. **冷启动清单做成 checklist 工具**：发布前敏感词检查 → 发布后 10min 收录自查 → 自置长评论 → 前 5 条评论 5min 内回复。**互动动作留人工，系统只做提醒和素材准备。**
7. **规格校验器**：标题 ≤20 字且前 8-13 字含目标长尾词、正文 300-800 字、封面 1080×1440、配图 4-8 张、标签 3-5 个、前 80 字埋词、核心词出现 2-3 次（防堆砌限流）。这些是确定性规则，**最容易做出真实价值**。
8. **视觉素材 15 天生命周期要做成提醒**——同一套封面模板每 ~2 周必须换新，否则明显掉量。
9. **算法参数全部可配置 + 标注来源**。CES 公式和流量池门槛**官方从未公开**，是行业经验值；写进系统时必须标为「经验参数」，不要硬编码为「平台规则」。
10. **产品红线明确写入需求文档**：不做自动养号/自动互动/自动私信、不做爬虫、不做导流话术生成、不做 AI 标识规避。这不只是合规要求，也是产品可持续性的保障（多起诉讼已证明平台规则边界模糊、判罚不确定）。
