## v0.2.0 · UI 主题改造（feat/ui-theme）

**日期**：2026-10-04
**基线标签**：`v0.1.0-before-ui`

### 背景
原界面为「灰白 + 橙色点缀」的朴素风格，信息密度高但视觉层级弱、缺少品牌感。
本次按参考设计稿改造为**紫色渐变主题**：大圆角卡片、四色渐变功能卡、
紫色渐变侧栏 + 白色药丸选中态、柔和阴影。

### 改造范围（仅表现层）
| 文件 | 改动 |
|---|---|
| `src/index.css` | 设计令牌全量重建：色板、圆角、阴影、字体层级、暗色模式 |
| `src/components/ui.tsx` | 基础组件视觉（徽章/统计块/空状态/状态点） |
| `src/App.tsx` | 布局骨架、侧栏、顶栏、各页卡片 |
| `src/components/FlowCanvas.tsx` | 流程图配色对齐新主题 |
| `src/components/AgentChat.tsx` | 侧栏视觉、消息气泡 |
| `src/components/DraftEditor.tsx` | 表单控件、编辑器、校验面板 |

### 明确未改动
- `src/lib/api.ts` — 接口调用与数据流
- `src/lib/flow.ts` — 流程定义与状态计算
- `src/bridge/` — bridge 能力声明
- `backend/**` — 全部后端逻辑
- 所有业务规则与校验逻辑

## v0.1.0 · MVP 打通（feat/mvp-pipeline）

**日期**：2026-10-04

### 交付功能
| 模块 | 说明 |
|---|---|
| M1 采集 | RSS 源 feedparser 抓取，HTML 清洗，内容指纹去重，单源失败隔离 |
| M2 选题 | 合规黑名单前置过筛，长尾词抽取，人群识别，差异化维度标注 |
| M3 文案 | 稿件 CRUD + 确定性规格校验（标题/正文/埋词/标签/AI声明/合规） |
| 流程图 | AntV X6 双链路（图文 7 步 / 视频 8 步），状态由真实数据计算，节点可点击 |
| Agent | 内核 7 个业务工具，读写均落库 |
| bridge | hbridge v2.1 接入，4 个界面操作能力 |

### 技术栈
- 后端：FastAPI + SQLAlchemy 2 + SQLite（可切 PostgreSQL）
- 前端：Vite 6 + React 19 + TypeScript + Tailwind CSS 4
- 可视化：AntV X6 3.1.8
- 内核：dsh harness @ 127.0.0.1:8787（hbridge/2 协议）

### 关键决策
1. **采集走 RSS 而非小红书数据** — 避开判刑/判赔的合规风险
2. **发布只做半自动** — 平台 2026 明确封禁 AI 托管账号
3. **Agent 产出必须经工具落库** — 无工具时模型会编造内容
4. **前端不直连内核** — 内核带 shell 工具，必须经后端转发

### 已知缺陷
见 `docs/13-后续开发待办清单.md`。
