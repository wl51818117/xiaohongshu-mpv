# 小红书内容规格基线（2026）

> 用途：作为工作台「内容校验规则」的硬编码依据。所有素材生成模块产出后必须过本校验。
> 来源：多篇2026 年规范整理 + 平台规则交叉验证

## 一、图文链路规格

| 项 | 要求 | 说明 |
|---|---|---|
| 封面比例 | **3:4 竖版**（1242×1656px 或 1242×1660px） | 不是方形，方形在信息流里展示面积小 |
| 封面尺寸下限 | ≥1000×1000px，推荐 1242×1660 | |
| 图片数量 | 最多 18 张，**最佳 6-9 张** | |
| 单张大小 | ≤5MB（JPG/PNG/GIF，GIF≤10MB） | |
| 封面点击率门槛 | **<2.5% 很难晋级流量池** | 决定生图 prompt 的核心变量 |
| 封面文字 | ≤画面 30%，字体 ≤2 种，字号 ≥40pt，标题放视觉重心上1/3 | 避让右下时长角标与底部信息区 |
| 封面主体占比 | ≥画面 60%，背景简洁 | |
| 正文字数 | 500-1000 字，**前 2 行（约 50 字）决定是否被展开** | 开头必须痛点前置 |
| 标签数量 | 15-20 个，覆盖品类词/场景词/人群词 | 结构化配比，非堆砌 |
| 段落 | 每段 2-3 行，适配碎片化阅读 | |

### 图片顺序（内容化详情页结构）

```
1张  高点击率封面（决定打开率）
2张  产品全景（建立认知）
3-5张  细节特写（材质/工艺/成分）
6-8张  使用场景 / 对比效果
9张  价格 / 购买信息（合规前提下）
```

### 三类高点击封面

1. 前后对比图
2. 干货合集图
3. 痛点情绪反差图

## 二、视频链路规格

| 项 | 要求 |
|---|---|
| 比例 | **3:4 竖版（推荐）或 9:16**，禁止 16:9 横屏（会出黑边，展示面积极小）|
| 分辨率 | ≥1080p，码率留 **8-12Mbps**（平台会二次压缩，源片别压太低）|
| 时长 | 技术上限 5 分钟，**推荐 15-60 秒**，干货类 30-90 秒 |
| 格式 | MP4/MOV，≤500MB，≥25fps（推荐 30fps） |
| 封面 | **单独上传**，不要用视频第一帧（第一帧通常是空镜）|
| 封面尺寸 | 1080×1440（3:4） |
| 字幕 | 全程字幕，字号 ≥32pt，位置画面下方 1/5，**底部 15% 会被标题/点赞区遮挡** |
| 水印 | **严禁带其他平台水印/logo**，轻则限流重则不通过 |
| AI 音色 | 禁止合成他人声音/面孔 |

### 时间轴结构（完播率核心）

```
0-3秒    钩子：痛点 / 冲突画面 / 结果前置（禁止自我介绍、片头动画）
3-15秒   核心信息 / 卖点演示
15-40秒  过程展示 / 效果对比
40-60秒  收尾+ 引导
```

低于 15 秒往往还没建立信任就结束。视频笔记推荐权重比图文有 5%-15% 加成。

## 三、AI 内容标识（合规硬要求）

**所有 AI 参与创作的内容均需主动标识。**

| 事实 | 数值 |
|---|---|
| 2023 年上线 | 内容自主声明功能 |
| 2025-09-01 | 《人工智能生成合成内容标识办法》施行（显式+隐式标识）|
| 2026 年 | 平台日均打标笔记 **超30 万条** |
| 2026 年至今 | 处置 AI 不良行为超百万例 |
| 其中 | **AI 托管账号超 80 万个**被处置 |
| 其中 | AI 造假笔记近 15 万篇 |

### 平台鼓励（可放心用）
- AI 提升作品信息价值（复杂知识可视化）
- AI 创作有辨识度的虚拟角色 / IP 二次创作
- AI 视觉创作（有审美、有叙事）
- AI 辅助剪辑、配音、字幕等**后期处理**
- AI 做内容调研、素材参考、二次创作

### 平台反对（四条红线，按违规程度梯度处理：限曝光 → 警告 → 封禁）

| # | 红线 | 系统对应措施 |
|---|---|---|
| 1 | **信息不透明**：AI 生成真人形象/图片/视频不声明；大量 AI 改写原创度存疑 | 素材层强制打`ai_generated` 标记，发布时强制勾选AI 声明 |
| 2 | **AI 违规运营**：云端AI 工具或手机脚本自动托管账号、冒充真人互动；AI 洗稿/去水印/规避审核 | **禁止全自动发布**；互动必须人工确认 |
| 3 | **AI 造假**：仿冒名人、虚构人设、伪造个人经历、编造虚假信息| 文案层提示词禁止编造经历；不生成虚假体验 |
| 4 | **AI 侵权**：侵犯肖像权、著作权 | 生图禁止真实名人脸；字体/音乐用可商用授权 |
| 5 | **低质创作**：批量同质化、猎奇博眼球 | 同质化检测（相似度阈值）|

> **关键认知**：AI 标识贴条**不影响流量**（平台明确），但**不标识会被强制贴条且属于违规**。
> 所以工作台应当"主动标识"而非"规避识别"。2026 Q1 平台还专门收紧了针对海外品牌的自动化行为打击。

## 四、其他易踩的坑

| 坑 | 后果 |
|---|---|
| 横屏 16:9 直传 | 两侧大黑边，展示面积极小，等于放弃流量 |
| 封面用视频第一帧 | 第一帧是空镜，点击率差 |
| 字幕贴边 | 被标题/点赞区遮挡 |
| 图片堆超大文件 | 上传失败率升高，无任何推荐加成 |
| 频繁编辑/删除笔记 | 限流恢复需1-4 周 |
| 一机多号 / 刷赞刷粉 / 频繁改昵称 | 明确违规 |

## 五、类目特殊要求（按需扩展）

- **美妆护肤**：必须展示真实使用过程；特殊化妆品需批准文号；禁"医美级""美白丸"
- **服装穿搭**：主图 3:4 长图（750×1000+），色差 ΔE<3，灯光 CRI≥95
- **家居收纳**：改造前后对比；不得夸大（禁"1㎡当10㎡"）
- **食品保健**：必须展示 SC 编号、配料表、保质期；禁"减肥""治病"

## 六、给工作台的校验清单（发布前必过）

```
[ ] 封面 1242×1660 (3:4)，文字≤30%，主体≥60%
[ ] 图片 6-9 张，结构完整（封面→全景→细节→场景→价格）
[ ] 视频 1080p / 3:4或9:16 / ≥25fps / 码率 8-12Mbps
[ ] 视频前 3 秒有钩子，无空镜无片头
[ ] 底部 15% 无字幕，顶部无状态栏内容
[ ] 无其他平台水印/logo
[ ] 正文 ≥500 字，前 50 字痛点前置
[ ] 标签 15-20 个，品类/场景/人群三类齐备
[ ] 无极限词、无虚假夸大、无隐晦导流
[ ] **AI 标识已勾选**（含 AI 虚拟人身份）
[ ] 同质化检测通过
```
