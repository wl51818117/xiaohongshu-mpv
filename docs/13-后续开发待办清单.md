## 五、下一次迭代建议顺序

```
1. 确认账号赛道 → 换 RSS 源                    ← 阻塞后续所有内容产出
2. 验证 Agent 界面操作端到端                    ← 打通 bridge 的最后一环
3. 实现 AI 生图（封面 + 内页）                   ← 让图文链路真正能产出
4. 实现半自动发布                              ← 形成完整闭环
5. 数据回流 + 爆文复用                         ← 闭环的最后一环
```

**理由**：1 是阻塞项（源不对，后面产出的内容方向就不对）；2 是已投入能力的验证；3-5 是把「选题有了」变成「内容能发出去」。
