## 三、🔒 阻塞项（需外部条件）

### 3.1 半自动发布（M6）— 需扫码登录

**当前状态**：架构已定（`xhs_ai_publisher` Apache-2.0，登录态复用方案成熟），但**未跑通**。

**阻塞原因**：需要真实小红书账号的扫码登录态。

**前置条件**：
1. 你提供一个测试用小红书账号（**建议小号**，别用主号）
2. 在本机跑 `xhs_ai_publisher`（Docker）
3. 扫码登录，保存登录态
4. 接进工作台：botDetect 风控探测 → 自动预填 → **人工点发布**

**⚠️ 红线不可破**：
- 平台 2026 明确封禁 AI 托管账号（已处置 80 万+）
- 必须保留「人工点发布」这一步，绝不做全自动
- 建议先拿小号验证半自动路线可行，再投入

### 3.2 账号赛道确认 — 影响内容方向

**当前**：RSS 有 5 个预设（科技/综合/生活/服饰内衣/电商），默认第一个。
**实测**：服饰内衣预设里Vogue 返回 200 但 0 条（内容在 JS 里），实际有效源是界面新闻/爱范儿/少数派。

**需要你定**：这个号做什么内容？定了我把预设调成默认，并补对应的 RSS 源（可用 RSSHub 自建）。

## 七、建议的下一步顺序

```
1. 确认账号赛道           ← 阻塞后续所有内容产出
2. 接 AI 生图 API         ← 让素材工坊真的能出图
3. 扫码登录 + 半自动发布  ← 需要小号，形成完整闭环
4. 去 AI 味 + 选题接 LLM  ← 提升内容质量
5. Alembic + 鉴权+ 暗色切换← 工程完善
```

**理由**：1 是内容方向的根本；2 让已完成的素材工坊真正可用；3 需要你的账号配合，越早开始越好；4-5 是质量与工程完善，可以并行推。
