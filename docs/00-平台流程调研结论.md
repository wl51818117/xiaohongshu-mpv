## 二、选题环节（系统重点）

### 2.1 选题来源（7 条渠道）

| 渠道 | 具体做法 | 可自动化程度 |
|---|---|---|
| 搜索下拉框 | 输入赛道词，记录全部联想词 | 半自动（插件/录入） |
| 关键词规划 | 月搜索量 >1万 且竞争笔记 <500 篇的词优先布局 | 半自动 |
| 爆文评论区 | 高频提问直接变选题 | 自动（已有采集数据时）|
| 创作者中心热门话题 | 提前布局，等热度过了就晚| 半自动 |
| 竞品对标 | 拆解近期爆文结构 | 半自动 |
| 用户私信/客服问题 | 真实需求 | 人工录入 |
| AI 灵感生成 | 基于以上数据扩选题 | 自动 |

**[行业]** 每周固定储备 15-20 个选题，别等发之前现想。

### 2.2 选题筛选标准

**[行业]** 一句话标准：**痛点解决 + 可实操 + 有信息增量**。
自嗨流水账和纯硬广直接毙掉。

### 2.3 内容配比

**[行业]** **7:2:1**
- 70% 干货/测评/教程 → 拉收藏
- 20% 热点/场景 → 冲推荐流
- 10% 人设/故事 → 提粉丝粘性

### 2.4 爆款选题公式

| 类型 | 公式结构 | 适用品类 |
|---|---|---|
| 搜索需求型 | 「怎么做/如何选/哪款好」+ 品类词 | 美妆、家居、数码 |
| 情绪共鸣型 | 痛点场景 + 解决方案 | 职场、育儿、减脂 |
| 清单合集型 | 数字 + 品类 + 场景 | 穿搭、旅游、食谱 |
| 对比测评型 | 产品A vs 产品B + 结论 | 消费电子、护肤 |
| 经验分享型 | 「我踩过的坑/我发现的方法」 | 通用 |

## 三、数据获取可行性（决定系统怎么做）

### 3.1 官方开放平台：**没有内容类目**

**[官方]** 小红书开放平台（open.xiaohongshu.com）支持的开发者应用类目**全部是电商侧**：

| 类目 | 能力 |
|---|---|
| 一键搬家 | 商品复制采集、上传、全店上传 |
| 商品优化 | 商品编辑、智能水印/logo、违禁词监测 |
| 打单工具 | 电子面单、批量打单 |
| 订单管理 | 订单同步、售后管理 |
| 企业 ERP / 跨境 ERP | 商品/订单/采购/库存/售后/财务 |
| 商家后台系统 | **所有权限包** |

> **结论：官方没有「笔记发布」接口，也拿不到笔记数据。**
> 这直接否定了"爬官方 API 做内容运营"的技术路线。

### 3.2 第三方数据平台（推荐主路径）

新红 / 千瓜 / 灰豚 / 蝉小红等，提供：
- 笔记列表与详情（标题、正文、图片、话题、作者、发布时间）
- 互动数据（点赞/收藏/评论数）
- 评论区内容
- 博主画像与粉丝数据
- 关键词热度、爆文榜、涨粉榜

**优势**：合规（买数据不碰平台）、稳定、可商用、字段完整。
**成本**：按席位/按量付费，需按最新报价核实。

### 3.3 爬虫方案：不建议做

**[行业+海外媒体交叉]** 结论一致：反向工程 App 的抓取/发布方案
- 违反平台服务条款 → **账号封禁风险**
- 可能**静默失败**（发出去没报错，实际没发）
- 字段残缺、稳定性无保证
- 无海外品牌可申请的内容发布 API（PostRSS 2026 报告明确指出这点）

## 四、内容生产规范（摘要）

完整规格见 `02-内容规格与合规基线.md`。核心要点：

### 图文
- 封面 3:4（1242×1660），点击率 **<2.5% 难晋级流量池**
- 正文 500-1000 字，**前 50 字决定是否被展开**
- 标签 15-20 个
- 图片 6-9 张，最佳顺序：封面 → 全景 → 细节 → 场景 → 价格

### 视频
- 3:4 竖版或 9:16，**禁16:9 横屏**（出黑边）
- 15-60 秒，1080p，码率 8-12Mbps
- **0-3 秒强钩子**，禁片头动画
- 封面单独出，**不要用第一帧**
- 字幕避让底部 15%

### 去AI 味（**[行业]** 重要）
小红书用户对 AI 味耐受度低，容易被识别并限流。
建议：AI 生成后用口语化方式重写，加入个人经历和真实感受。
平台鼓励的 AI 用法：提升信息价值、有辨识度的虚拟角色、视觉创作、辅助剪辑配音。

## 五、发布与冷启动

### 5.1 发布时间
**[行业]** 工作日 12:00-13:30、18:00-23:00；周末优先上午 10 点、晚 20-22 点。

### 5.2 冷启动（前 60 分钟赛马）
**[行业]** 前 2 小时是黄金期：
- 发布后 5 分钟 / 30 分钟 / 60 分钟三层赛马
- 发布 10 分钟后用小号搜全称确认收录
- 自己置顶一条 15字以上的长评论抛话题
- 前 5 条真实评论 **5 分钟内回复**

### 5.3 CES 权重与流量池
**[行业]** 权重排序（2026 口径）：
```
关注 ×8 > 评论 ×4 = 转发 ×4 > 收藏 ×1 = 点赞 ×1
```
**注意**：CES 评分与阶梯流量池的具体算法权重为**第三方总结**，非官方公开口径，落地时以实际后台数据为准。

### 5.4 投流
**[行业]** 先测后投、优质放大：
- 薯条单条测试预算 75-200 元，时长 6-24 小时
- 加投条件：点击率 >5%、收藏率高、评论正向
- 弃投条件：曝光高但点击低
- 聚光放大条件：24 小时内自然赞藏 >300、互动率高于同期均值

## 七、合规红线（[官方] 最重要）

### 7.1 AI 标识（必须）

| 事实 | 数值 |
|---|---|
| 2026 年日均打标笔记 | **超 30 万条** |
| 2026 年至今处置 AI 不良行为 | **超百万例** |
| AI 托管账号被处置 | **超 80 万个** |
| AI 造假笔记 | **近 15 万篇** |

**关键点**：AI 标识贴条**不影响流量**，不标识才违规。
《人工智能生成合成内容标识办法》2025-09-01 施行，显式+隐式标识均有法律要求。

### 7.2 五条红线（平台反对）

| # | 红线 | 例子 | 系统对策 |
|---|---|---|---|
| 1 | 信息不透明 | AI 生成真人形象/图/视频不声明；大量 AI 改写 | 强制 ai_flag 字段 |
| 2 | **AI 违规运营** | 云端 AI 工具/手机脚本**自动托管账号**、冒充真人互动；传授洗稿/去水印/规避审核 | **禁止全自动发布** |
| 3 | AI 造假 | 仿冒名人、虚构人设、伪造个人经历、编造虚假信息 | 提示词禁编造经历 |
| 4 | AI 侵权 | 侵犯肖像权、著作权 | 禁名人脸；字体/音乐用可商用 |
| 5 | 低质创作 | 批量同质化、猎奇博眼球 | 同质化相似度检测 |

### 7.3 处理方式
梯度处理：**限制曝光 → 警告 → 封禁**。
对明确由 AI 托管运营、无真实人类参与的账号，**予以封禁**。

### 7.4 其他违规行为
一机多号、刷赞刷粉、频繁改昵称简介、连续发同质化洗稿内容、隐晦导流话术、素材带其他平台水印。
限流恢复周期：多数 1-4 周自动恢复，期间不要频繁编辑或删除笔记。

## 八、调研结论对系统的三条决定性影响

| # | 平台事实 | 对系统的硬性要求 |
|---|---|---|
| 1 | 官方开放平台**无笔记发布接口、无笔记数据** | 采集走第三方数据平台；发布只能半自动或人工 |
| 2 | 2026 明确**封禁 AI 托管账号**（已处置 80 万+）| 绝不 AI 全自动发布；Agent 只做到"预填 + 人工点" |
| 3 | AI 内容**必须主动标识**，贴条不影响流量 | 素材层强制 ai_flag，发布必带声明 |
| 4 | **爬虫有司法判例**：2025上海知产法院二审，爬取笔记数据售卖、调用 294 万次、获利 11 万，**判赔 110 万**不正当竞争；杭州中院判赔 490 万 | 采集层只能走第三方付费 API，绝不自建爬虫 |
| 5 | 私信导流是明令禁止（2025-03-12《交易导流违规管理细则》），陌生人私信 24h 内≤1 条、累计≤3 条 | 系统**不提供任何导流话术生成能力** |

## 九、核心情报补充（来自深度调研，影响系统设计）

### 9.1 数据获取的合法边界（判例级）

| 行为 | 风险判定 |
|---|---|
| 自建爬虫抓笔记/评论/用户数据 | 🔴 **判例：110 万赔偿**，「绕过技术防护」是不正当竞争认定要件 |
| 抓取数据对外售卖/给第三方 | 🔴 判罚显著加重，已是明面违法 |
| 破解 x-s/x-t 签名、绕验证码、绕限频 | 🔴 「绕技术措施」是法院明确认定的要件 |
| 抓用户手机号/住址/后台数据 | 🔴 侵犯个人隐私，涉刑 |
| 自用少量、不破技术措施、不二次售卖 | 🟡 边界模糊，仍有风险 |

**系统决策**：数据层做双轨——官方 API（自有账号数据 + 关键词 + 投流）+ 第三方付费 API（竞品/话题/达人）。**不建爬虫**。

### 9.2 官方 API 的真实能力边界

| 渠道 | 能拿到什么 | 门槛 |
|---|---|---|
| 开放平台 | **仅自有授权账号**笔记详情/作品列表/商品搜索；v4 新增**视频播放量、完播率** | 企业资质或身份证+手持照；每类权限人工复核，审核 1-3 工作日 |
| 聚光 | KOS 报表数据 + **关键词规划工具**（搜索量、竞争热度、建议出价） | 超管账号；需全新干净手机号 |
| 蒲公英 | 博主粉丝画像、报价、近 30 天 GMV、种草指数 | 企业蓝V + 营业执照 |
| 创作者中心 | 自有笔记曝光/点击/完读/互动/涨粉 + **笔记诊断** | 零门槛 |

技术约束：OAuth 2.0，access_token **有效期 2 小时**（需自动刷新）；敏感操作需 HMAC-SHA256 签名；频率限制 200 次/分钟（企业可提至 500）。

> **结论：官方 API 只支撑「自有账号数据分析 + 投流 + 关键词规划」三件事。竞品/对标/爆文库必须走第三方。**

### 9.3 第三方数据平台价格量级

| 平台 | 价格（公开口径） | 强项 |
|---|---|---|
| 千瓜数据 | 高级版 ¥1599/月、专业版 ¥2599/月 | 品牌投放分析、热搜词库、违禁词检测、**视频 AI 解析** |
| 新红数据 | ¥888-5888/月 | 内容趋势、爆文追踪 |
| 灰豚数据 | ¥688-3988/月 | 关键词搜索量+竞争度、直播转化 |
| 热点雷达 | ¥6-18/月 | 低粉爆文发现、按爆款系数排名 |
| Rnote API 等 | 充值制 | `/api/v2/crawler` + `/api/v2/pgy`，X-API-Key 认证，无需绑定小红书账号 |

**三大坑**：① 互动数据多为预估值；② 不同工具对同一词搜索量可差 **3 倍**→固定一家做纵向对比；③ 正规工具只读公开数据，**任何索要小红书账号密码的都是黑产**。

### 9.4 投流阈值（可直接写进代码做自动触发）

| 工具 | 触发条件 | 节奏 |
|---|---|---|
| **薯条** | 封面点击率 **≥5%** 且完读率 **≥40%** | 观测：6h+75元 → 放大：互动率≥8% 投12h → 收割：拆 2-3 单 |
| **聚光** | 48h 赞藏 **≥100** 且点击率 **≥3%** | 日预算 300-500 元/计划；学习期 24-48h 内每天调≤2 次 |

标准打法：**薯条测素材 → 信息流种草 → 搜索收割 → 全站智投放量**

### 9.5 选题量化筛选标准（可直接落库）

```
选题因子叠加公式：人群 × 场景 × 痛点 × 形式
例：上班族 × 办公室 × 不长胖 × 食谱
九宫格法（3×3）可一次性产出几十个候选
```

| 维度 | 判据 |
|---|---|
| **竞争度** | 同题笔记 ≤10 篇 = 蓝海（优先）；>50 篇 =红海（慎选） |
| **实操验证**（比工具分可靠）| 搜该词看**前 20 篇**的发布日期与互动量，若大量高互动老笔记 → 壁垒已高，新号不宜正面进|
| 关键词分层 | 核心词（月搜 1万+）/ **长尾词（1000-1万，性价比最高）**/ 蓝海词 |
| 价值类型 | 情绪/实用/信息/经济（至少占 1 种） |
| 痛点句式信号词 | `求推荐` `怎么买` `多少钱` `适合XX吗` `和XX比哪个好` |
| 选题配比 | **纯流量选题 : 变现选题 = 7 : 3** |

**对标调研进阶技巧**：不看对标账号"哪篇最火"，而看**哪篇超出了它自己的平均水平**——计算近 30 篇平均点赞，把 **高于平均 2 倍以上**的选题标为「已验证入池选题」直接拿来用。

### 9.6 标题与埋词（搜索权重第一来源）

- 标题 **≤20 字**（硬上限），**前 8-13 字必须含核心长尾词**
- 前 80 字埋价值 + 主关键词（否则被折叠）
- 2026 语义理解看整体相关性，**核心词自然出现 2-3 次即可，硬堆 5 次会触发限流**
- 首行不要空格缩进（会被判机器号）

### 9.7 视频中长视频是2026 扶持方向（重要机会）

| 事实 | 数据 |
|---|---|
| 月中长视频发布量 | >1000 万条，4200 万创作者参与 |
| 消费时长 | 同比 **+43%** |
| 推荐有效期 | 延长至 **90 天**（图文仅 15-20 天） |
| 视频初始曝光 | 比图文 **高约 30%** |
| 核心评估信号 | 收藏量、关注行为、**完整播放时长**（替代完播率）、弹幕互动 |

视频脚本结构（可直接做模板）：
```
0-3s钩子（反差结果/直戳痛点/先给结论）
3-6s   建立可信（身份+经历+数据背书）
6-45s  主体（结论→演示→注意事项；要点含可执行动作/最常见误区/立刻见效技巧）
45-60s结尾转化（行动指令+理由+低门槛）
```
切镜节奏 **2-3 秒一切**；每 15 秒给一次小高潮；AI 单镜头最佳 3-5 秒。

**结论：图文 + 视频双轨最优——图文抢搜索（生命周期 15-20 天），视频冲推荐（长尾 90 天），图文爆款可二次改编成视频。**

### 9.8 素材生命周期 15 天（易被忽略的运营情报）

滤镜化旧素材掉量明显，**新素材生命周期约 15 天**。同一套封面模板要**每 ~2 周换一次视觉**，否则明显掉量。
→ **系统应做素材新鲜度提醒**。

### 9.9 自动化可行性分级（系统设计的直接依据）

| 等级 | 内容 |
|---|---|
| 🟢 **可全自动** | 自有账号数据采集、关键词监控、选题库 CRUD、因子叠加生成、AI 辅助生成（标题/正文/脚本/图/视频）、违禁词检测、**规格校验**、排名监测、复盘报表、投流参数计算 |
| 🟡 **半自动**（需人确认）| 发布、收录自查、私信互动（AI 辅助草稿）、素材选片修图、评论区运营 |

| ⚫ **灰色地带**（不做）| 自建爬虫、破解签名、帮用户规避 AI 标识、**生成导流话术/私信钩子** |

### 9.10 私域导流是产品级红线

2025-01-07 起专业号私信自动回复**禁止出现微信及电话**；2025-03-12《交易导流违规管理细则》禁止通过官方组件外任何形式引导站外交易。
私信频次：陌生人 24h 内最多 1 条，累计 ≤3 条；同话术发给 ≥3 人触发批量营销预警。

**系统绝不能提供导流话术生成能力**——已有诉讼争议，判定边界模糊。

### 9.11 定位偏离的量化诊断（可做成系统功能）

- **内容标签重合度验证法**：系统自动打的推荐标签 vs 账号定位核心词，**重合度 <60% 即判定内容偏离定位**
- **评论区高频疑问诊断**：「你到底是卖什么的?」≥5 次 = 商业定位模糊；「你是不是专门做这个的?」≥5 次 = 人设标签不清
- **流量平权**：2026 年新号与百万粉账号初始流量池标准一致（200-500 曝光），超 50% 大盘流量向千粉以下倾斜

### 9.12 数据自购成本参考

2025 年小红书电商 GMV突破 **8500 亿元**；搜索侧月活 >4 亿、日搜索量 **8 亿次**、搜索流量占比逼近 **50%**，约 30% 用户打开 App 直接搜索。

> 2026 最重要的变化是**「搜索流量 + 语义理解」双升级**，而非 CES 权重。选题系统应从「追热点」转向**「长尾词布局」**。

### 9.13 算法参数必须可配置（重要工程要求）

⚠️ CES 公式与流量池门槛**均为行业口径，官方从未公开确认**。
系统写代码时必须：
- 标注为「**经验参数**」而非「平台规则」
- 全部可通过配置文件调整
- 数据来源标注（官方 / 行业 / 推测）
